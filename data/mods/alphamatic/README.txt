The Alphamatic 3.0 by Gridlock

Unpack your copy of TheAlphamatic_v3.0.zip here. A single extra folder
inside this folder is supported. Keep ALPHAM.CK5 beside this README.
The game runs natively in Keen Worlds; no DOS executable is run.

This adventure follows Atroxian Realm. Free Flight can visit it directly.
In the Chronicle, finish Atroxian Realm first (when it is installed).

Conversion provenance: kwtools/kw_alphamatic.py; gameplay: src/kw_alphamatic.c.
The tool reads your own unmodified Keen 5 v1.4 EXE if regenerating support.
